## 每GB内存成本：比月费更可靠的比价指标

直接比月费会得出很怪的结论：6.99 美元的 Contabo 看着比 4.59 美元的 Hetzner 贵一半，实际每GB内存只花 0.87 美元，反而是表里最便宜的。内存是对网站类负载影响最直接的资源——CPU 大部分应用吃不满，存储各家都不贵，流量要上量了才心疼——所以比价先算这一项。

按这个指标，主流厂商分三档：

- **预算档（0.87–2.00 美元/GB）**：Contabo 0.87、Hetzner 1.15、Hostinger 1.62、RackNerd 1.75
- **中间档（3.00–5.00 美元/GB）**：InterServer 3.00、Kamatera 4.00、BuyVM 4.00、Vultr 5.00、Linode 5.00
- **高价档（5.00 美元/GB 以上）**：DigitalOcean 6.00、ScalaHosting 7.49

高价档多出来的钱花在周边：DigitalOcean 的 SSD 读取约 55,000 IOPS，Contabo 的 SATA SSD 只有约 25,000；DO 支持按秒计费、有 API 和快照，托管数据库、文档和社区都是现成的。ScalaHosting 每GB 7.49 美元，贵在全托管服务，付的主要是人力。中间档则是平衡点，Vultr 和 Linode 在这个价位给足了计费灵活性、API 和机房选择。

预算档四家各有一个明显的短板：Contabo I/O 慢、不支持按小时计费、没有 API；Hetzner 美国机房只有两个（弗吉尼亚 Ashburn，加上 2026 年新增的俄勒冈 Hillsboro）；Hostinger 续费涨价；RackNerd 没有备份和 API。跑游戏服、开发环境、吃资源的自建应用——这些只看裸配置的场景里，预算档就是甜点位，短板踩不中你就没必要为用不到的功能付钱。

## 常见问题

**为什么同配置的VPS价格能差好几倍？**
差价主要来自四块：存储性能（DigitalOcean 约 55,000 IOPS 对 Contabo 约 25,000）、计费粒度（能不能按小时开停）、自动化能力（有无 API）和支持质量。裸配置相同，周边不同，价格自然拉开。

**1TB 月流量够用吗？**
纯文字博客、作品集、低流量应用基本用不完；图床、下载站、视频类服务会很快超。吃流量的场景优先看 Contabo（今年从 20TB 提到 32TB，价格没变）和 Hetzner（20TB）这类大流量方案，而不是抠内存。

**首期便宜续费贵，正常吗？**
小幅上涨是常态（市场中位数从 9.95 美元涨到 11.46 美元），8 倍涨幅（BuyVPS，1 美元续费 7.99 美元）这种就要当心了。下单前在购物车页确认续费条款，按 24 个月算总账。

**便宜的 VPS 和 AWS 这类云平台怎么选？**
纯比价格不占优：AWS t3.micro、Azure B1s 起步 7.59 美元/月，规格不如传统厂商 5 美元档；Heroku 最小方案 25 美元/月。大厂的价值在生态、合规和现有架构整合，如果只是要一台跑网站的机器，传统 VPS 厂商便宜得多。
